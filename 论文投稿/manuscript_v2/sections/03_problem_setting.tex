\section{Experimental Setting and Warm-Start KD}
\label{sec:problem-setting}

We ask whether a frozen teacher improves an already trained autoregressive student beyond matched maximum-likelihood continuation. For each seed, the same validation-selected checkpoint $S_0$ initializes a CE arm and a CE+KD arm. Both load identical weights, reset the optimizer, and use the same continuation data and budget. Each arm independently selects a checkpoint by validation NLL; test NLL is evaluated only after selection. Figure~\ref{fig:paired_protocol} summarizes this design.

Let $p_{\mathrm{teach},i}^{(\tau)}$ and $p_{\mathrm{stud},i}^{(\tau)}$ be teacher and student next-token distributions at temperature $\tau$. Over valid positions $\mathcal{I}$, excluding masked targets after the causal shift, we use
\begin{align}
\mathcal{L} &= \mathcal{L}_{\mathrm{CE}}+\lambda\mathcal{L}_{\mathrm{distill}},\label{eq:kd-objective}\\
\mathcal{L}_{\mathrm{distill}} &=
\frac{\tau^2}{|\mathcal{I}|}\sum_{i\in\mathcal{I}}
\mathrm{KL}\!\left(p_{\mathrm{teach},i}^{(\tau)}
\,\|\,p_{\mathrm{stud},i}^{(\tau)}\right).\nonumber
\end{align}
Both terms are averaged over target tokens. This \texttt{token\_mean} normalization differs from the batch-normalized KL used in some legacy runs. Primary comparisons fix $\tau=2$ and $\lambda=5$; matched CE uses $\lambda=0$.

The protocol-specific paired transfer endpoint is
\begin{equation}
\mathrm{Gain}_{\mathrm{KD}}=
\mathrm{NLL}_{\mathrm{CE}}^{\mathrm{test}}-
\mathrm{NLL}_{\mathrm{KD}}^{\mathrm{test}}.
\label{eq:paired-gain}
\end{equation}
Positive gain means that KD improves over CE continuation, not necessarily over $S_0$. An unrelated baseline would confound this comparison with initialization or training history. Whether continuation itself remains useful is examined separately in Section~\ref{sec:external-validity}.

We report gains for three independently prepared student seeds, 42, 123, and 456, with their mean, sample SD, and sign consistency. These replications vary student preparation, not teacher training or corpus collection. The SD is descriptive, not a standard error or significance test. Primary endpoints select among trained continuation checkpoints. An explicitly labeled diagnostic also permits the unmodified $S_0$ as step 0; it does not replace the primary endpoint.
