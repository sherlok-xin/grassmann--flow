# Focused prior-art audit — Phase 5

Checked 2026-11-25. These comparisons constrain claims; they do not establish novelty by exclusion. Implemented baselines are adaptations to the same Phase 5 token objective, architecture, data and optimizer, not reproductions of published benchmark scores. Actual Phase 5 wall times are recorded separately. No published speedup is substituted for our measurements.

| Work and primary source | Target/reference and feedback | Optimizer state / extra data / compute | Verified implementation and implication for Phase 5 |
|---|---|---|---|
| [ATKD, ACL 2024](https://aclanthology.org/2024.acl-long.587/) | Separates target/non-target binary KL from conditional non-target KL; teacher uncertainty partitions easy/hard tokens. | No independent CE trajectory or held-out feedback; teacher inference plus token-loss processing. | [Author code](https://github.com/WHU-ZQH/ATKD/blob/71802dc4ca7b6d911af6922df65dfe586db81b00/distill/distill_trainer.py), `atkd` and `get_tckd_nckd`, inspected. Phase 5 uses global optimizer-batch median, separate easy/hard means, weights 0.2/0.8. Decoupling is existing work, not our contribution. |
| [TAID, ICLR 2025](https://arxiv.org/html/2501.16937v4) | An intermediate distribution interpolates detached current-student and teacher logits; the interpolation advances using training-loss progress and a schedule. | Additional scalar momentum/schedule state, no independent CE model and no validation-driven parameter fork. | [Author loss](https://github.com/SakanaAI/TAID/blob/a0628922c16169d1fca10ddf61849e0693289cf8/src/distil_losses/taid.py) inspected. This is logit interpolation, not the probability mixture in A. ToDi is the preregistered modern-divergence baseline; we do not claim a TAID reproduction. |
| [ToDi, EMNLP 2025](https://aclanthology.org/2025.emnlp-main.409/) | Vocabulary-wise forward/reverse KL combination with a detached sigmoid of teacher/student log-probability ratio. | Current student is the feedback source; no separate reference trajectory or control documents. Extra loss arithmetic but no extra model training. | [Author implementation](https://github.com/jungseongryong/ToDi/blob/1d1dd9efbdbeeae281130b184f29fde2aaf79cff/code/criterions/various_divergence.py), `compute_ToDi`, inspected. Phase 5 adapts that divergence with beta=1, mask/token averaging and matched CE term. |
| [CHAD, AACL 2026](https://aclanthology.org/2026.aacl-short.4/) | Uses validation-gradient alignment to label a training probe and fit a cheap per-example gate; distinct from the accompanying EWAD+CPDP construction. | Requires probe gradients, held-out reference labels and gate fitting. A local directional proxy is not a complete AdamW rollout. | Paper methods inspected. An unambiguous author-code URL was not located in the paper or bounded search; no exact CHAD reproduction is claimed. Phase 5 diagnostics and B must be compared with this prior validation-feedback idea. |
| [MetaDistil, ACL 2022](https://aclanthology.org/2022.acl-long.485/) | A temporary student update is evaluated on quiz data to meta-update the teacher; the original student then learns from the updated teacher. | Trainable teacher, differentiable pilot and extra quiz data/updates. This differs from a frozen teacher and a copied full AdamW continuation state. | [Author repository](https://github.com/JetRunner/MetaDistil/tree/80e60c11de531b10d1f06ceb2b71c70665bb6aff), NLP distillation implementation inspected. Its logits/features loss differs from our forward-KL objective. A pilot update or held-out feedback alone cannot be claimed as new. |
| [CUD, Findings EMNLP 2026](https://aclanthology.org/2026.findings-emnlp.2435/) | Combines teacher-side DUS adaptation with W-Clip correction of incorrect predictions; W-Clip transfers probability from an incorrect maximum to the labeled target. | Full CUD includes teacher training. W-Clip alone only modifies output targets. Neither uses our independently advancing CE reference. | Paper equations 5–9 inspected; author code not located in bounded primary-source search. Phase 5 implements **W-Clip component only**, eta=0.5 and margin=0.7, at token level. It is not full CUD; language references also need not be uniquely correct. |
| [Knowledge Distillation with Refined Logits, ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Sun_Knowledge_Distillation_with_Refined_Logits_ICCV_2025_paper.html) | Classification logit refinement separates semantic-confidence and masked-class distillation, using labels and teacher confidence. | No independent CE training trajectory. Label-conditioned target correction already exists. | CVF metadata located; direct PDF retrieval returned HTTP 403. [Author RLD implementation](https://github.com/zju-SWJ/RLD/blob/d54578fd77cd669d6209be4d05ae773bca4109b5/mdistiller/distillers/RLD.py) inspected: teacher maximum vs student gold binary KL and masking of teacher logits at/above the gold logit. Do not call A the first label-refined teacher. |
| [GRACE, ICLR 2026](https://arxiv.org/html/2511.02833v3) | Scores distributions of student gradients on teacher-generated responses to select teachers; studies reasoning tasks. | Teacher generations and student gradient measurements are required, not teacher logits or student optimization trajectories. | [Author repository](https://github.com/abhishekpanigrahi1996/GRACE) and paper inspected. This is teacher selection for response distillation, not per-token frozen-logit correction. Negative results for our old local metrics do not invalidate GRACE. |
| [FutureBridgeOPD](https://arxiv.org/abs/2608.01953) | Evaluates future agent interaction/generation trajectories when validating teacher guidance. | Lookahead environment/model inference costs, rather than the same AdamW model/moment state advanced on training batches. | Primary abstract/method context checked. Generation trajectory and training-parameter trajectory must remain distinct. No exact reproduction is claimed. |

Additional close neighbors include [learning to reweight with validation feedback](https://proceedings.mlr.press/v80/ren18a.html), [population-based online hyperparameter optimization](https://arxiv.org/abs/1711.09846), [Born Again Networks](https://arxiv.org/abs/1805.04770), [KD as semiparametric inference](https://arxiv.org/abs/2104.09732), [normalized KD / cross-entropy reformulation](https://arxiv.org/abs/2208.10139), and [KD regularization and example reweighting](https://arxiv.org/abs/2002.03532). These motivate the full-reference self-distillation, fixed-effective-weight, mean-beta and identity-permutation controls. They do not license a claim that independent CE references or adaptive loss weighting are categorically new.

A uses labels, a frozen teacher and an independent CE trajectory at the same update index. Its projection is exactly adaptive CE/KD reweighting at temperature one. The open empirical question is whether the independent trajectory contributes useful information beyond the current student, an average coefficient, an ordinary tuned coefficient or another CE model. All reference updates, extra eval-mode forwards, cache I/O, and search runs are charged. A matching student-update count is not a matching total-compute comparison.

B commits the complete selected model, AdamW moments and RNG state after a real short fork. The chosen minimal B is itself online hyperparameter search with an explicit control budget. Its matched online-search comparator is algorithmically identical, so the pilot cannot support a novel-controller claim. It can measure whether local incremental utility is useful and how much it costs. A CE branch forked from a KD state is not the S0-origin independent CE trajectory, and a positive short-horizon result is not proof of a better final endpoint.

Remaining source-verification limits are explicit: CHAD/CUD author code was not located; the RLD PDF was blocked but the author loss was inspected; complete GRACE/MetaDistil training-state implementations were not reproduced. These works are contextual comparisons, not measured Phase 5 baselines unless a run manifest explicitly says otherwise.
