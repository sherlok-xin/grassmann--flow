# Phase 5 live provenance

The independent branch starts from `99fd6632ee6042f85e709ac3a30b500e8ee1bbbb`.
The user's 2026-11-25 authorization supersedes historical STOP instructions only
for this new phase. The local working tree already contained unrelated changes;
they are preserved. Git mutations run locally, and heavy compute runs in the
existing 197 container via `exec_grassmann.sh`. No new cloud service is used.

Each completed run has a config, immutable summary, training trace and checkpoint
under `outputs/phase5`. Configs record initialization, teacher, data, protocol and
source hashes. `RUN_MANIFEST.csv` and `RESULTS.csv` are generated by `collect.py`;
smoke and screen rows are explicitly distinguished from full runs. A missing
summary is not a completed endpoint. `COSTS.csv` includes failed allocation time
and both original bootstrap smokes. Reference generation and evaluation are
charged. CPU waits and asset downloads do not occupy a GPU.

Pinned models/data and actual tokenizer/mask audits are in `modern_assets.json`
and `modern_data.json`. The modern queue requires `modern_assets_verified.json`,
which is generated only after all pinned weights match official LFS SHA256
metadata. A resumable download is not a successful verification. TLS checking
remains enabled; the existing local proxy is used without changing its settings.

The historical WT2 and TinyStories S0 checkpoints were selected using their
original validation sets. The new control/dev partition does not erase that
history. Old test results are already known and are not new held-out evidence.
The new summary-task test is frozen; data-integrity inspection is not model
evaluation. No Phase 5 test prediction has been generated at this checkpoint.

`protected_files.json` contains 150 historical manuscript, evidence and canonical
PDF hashes. `draft_qa.json` confirms that these files remain unchanged. This is
not a claim to have rehashed every historical checkpoint or every large raw log.
Old `datasets/` and `checkpoints/` are accessed read-only; all new large artifacts
are written under `outputs/phase5`.

extra time is charged. The first AdamW fork replay passed exact state replay but
then encountered an OOM when another job entered the same card. That incomplete
attempt is immutable, charged, and not counted as a method endpoint. The retry
has a distinct name. At the user's instruction, occupied GPUs are waited for;
no other jobs or GPU clocks are changed.
