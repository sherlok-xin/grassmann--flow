# Phase 5 — live evidence report

Status on 2026-11-25: implementation and bounded screening are in progress. This is **not a completed-method report**. Completed rows in `RESULTS.csv` distinguish smoke, short screen and full runs. No Phase 5 test endpoint has been evaluated. Historical ARR scores are 2/2/1; historical manuscripts and final evidence remain protected.

The temperature-one projection and its exact adaptive CE/KD gradient equivalence are implemented and tested. The current-student reference control uses an extra preupdate eval-mode forward, matching the probability-extraction mode of the independent CE cache. Separate controls remove token-specific weighting, replace the reference with S0 or the full independent CE distribution, and permute non-target identities. Their implementation is not evidence that they succeed. `METHOD.md` states the mathematical boundaries and `PRIOR_ART_MATRIX.md` identifies existing target correction, scheduling and validation-feedback work.

Six one-epoch WT2 CE screens have completed. Their trained dev NLL values at learning rates 1e-6, 5e-6, 1e-5, 2e-5, 5e-5 and 1e-4 are 4.348807, 4.353360, 4.357658, 4.363602, 4.369866 and 4.373888. All select S0 (4.348015) when step zero is included. The first matched KD screen, lambda=0.25, T=1 and lr=5e-5, reaches 4.337590 and selects its trained endpoint. These are exploratory short-budget results, not final ten-epoch effects or evidence of a successful new method. The preregistered full promotions and baseline/ablation matrix remain pending.

TinyStories has a prepared train/control/dev manifest. Its eight-update CE/cache smoke completed with finite gradients. Formal TinyStories training will start only after the missing paired KD/A smoke passes. The finite queue waits for an idle GPU instead of occupying memory while another project runs.

The real-AdamW replay smoke passed exact repeated-step model and optimizer equality with a nonzero learning rate. A subsequent fork stage encountered an out-of-memory error after another process entered the same physical GPU. The incomplete fork has no usable endpoint table and is not a method failure. Its allocated wall time is charged; an isolated retry is queued before formal fork analyses. The minimal B implementation is the same algorithm as the explicitly budget-matched online search comparator. It cannot support a novel-controller claim.

The new modern task is a pinned SmolTalk2 no-think short-summary subset. From 96,061 rows, 66,946 remain after complete-response length filtering and normalized-document deduplication. Preparation/continuation/control/dev/test contain 13,508/43,286/3,449/3,381/3,322 examples. Preparation has 575,227 unique response targets and continuation has 1,839,404. Larger target budgets repeat training examples. Full user instructions, including the dataset's separate custom-instructions field, are included in the prompt. Only assistant reference responses plus their end token are supervised. Synthetic references are not guaranteed factual answers. The lexical near-duplicate screen does not establish exhaustive semantic decontamination or pretraining decontamination.

Qwen3 base revisions are pinned in `modern_assets.json`; tokenizer ID mappings and every retained actual encoding match. Isolated Transformers/PEFT dependencies import successfully, and eight scientific tests pass. Model weights are still downloading with resumable, bounded retries; full-model throughput/memory smoke and modern training are not yet complete. `modern_resource_and_selection_rules` chooses a finite continuation budget from measured throughput before adaptation endpoints. No modern success, headroom, generation gain or three-seed confirmation may be claimed at this point.

The 230 GPU-hour value is an authorization ceiling, not consumed compute. `COSTS.csv` contains completed/failed allocation time and current status; the provisional 0.25 GPU-hour bootstrap reserve must be reconciled before final cost reporting. Cache generation, teacher adaptation, independent CE trajectories, failed probes and discarded controller branches count. Student-update matching is distinct from total-compute matching; WT2 cost controls use measured costs to choose approximate budgets and must report achieved ratios.

Server availability is shared and changes between launches. GPU 3 was observed at 210 MHz under load; the completed first CE screen is retained and charged. Subsequent WT2 work moved to GPU 0. Other processes later occupied all four GPUs, so subsequent jobs use idle waits. No other process, device clock, old dataset or old checkpoint has been changed. The first complete WT2/TinyStories/modern pilot batch and manuscript_v3 remain unfinished.
